**🌦️ Será que chove hoje?

Aplicação web responsiva para consulta da previsão do tempo em tempo real.
O usuário informa sua cidade e recebe os dados climáticos atualizados através da API OpenWeatherMap, explorando integração com serviços externos via JavaScript.

🔗 Acesse o projeto online: Clique aqui

🚀 Tecnologias utilizadas

HTML5 → estrutura da página

CSS3 (Flexbox) → estilização e layout responsivo

JavaScript (ES6+) → lógica de consumo da API e manipulação do DOM

API OpenWeatherMap → fornecimento dos dados meteorológicos

🔑 Sobre a API

O projeto utiliza a OpenWeatherMap API para exibir a previsão do tempo.
Essa foi uma oportunidade para explorar o trabalho com consumo de APIs, aprendendo sobre requisições HTTP e integração de dados externos em uma aplicação web.
